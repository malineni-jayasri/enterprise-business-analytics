
# Enterprise Business Analytics
## Project Overview
This project simulates a real-world Business Analyst/Data Analyst engagement for a building materials company. The objective is to analyze sales, pricing, customers, products, discounts, freight costs, and profitability to identify opportunities that improve business performance.
## Tools
- SQL
- Power BI
- Power Query
- Excel

## Project Goals
- Clean messy business data
- Build KPIs
- Create executive dashboards
- Generate business recommendations
- Present actionable insights

Project in Progress
